# Corpus for guard-corpus.sh: `<cwd> <expect> <command>`.
# cwd: outer (dirty) > mid (clean) > inner (clean) are nested; clean, dirty,
# cleansp ("clean dir"), dirtysp ("dirty dir"), home (dirty), fx (no repo).
# expect: `-` soundness only; `allow` the guard must pass it; `harm` the real
# run must hit a dirty repo / push / publish (and so the guard must refuse).
# `<NL>` is a newline. Every command runs for real with git shimmed.
